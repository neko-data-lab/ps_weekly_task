# パズサバ週間イベント確認ツール

## 公開方法（GitHub Pages）
1. GitHubで新しいPublicリポジトリを作成します。
2. このフォルダ内のファイルをすべてリポジトリ直下へアップロードします。
3. Settings → Pages → Deploy from a branch → `main` / `/(root)` を選択して保存します。
4. 公開されたURLをiPhoneのSafariで開き、「共有」→「ホーム画面に追加」を選びます。

## ファイル構成
- `index.html`：メイン画面
- `img1.png`：エースコマンダー週の表示画像（利用者が用意）
- `img2.jpg`：通常週の表示画像（利用者が用意）
- `style.css`：画面デザイン
- `app.js`：チェック状態・時間軸・表示制御
- `schedule.json`：共通週間スケジュール
- `admin.html` / `admin.js`：スケジュール編集・JSON入出力
- `manifest.json` / `service-worker.js`：PWA・オフラインキャッシュ

## スケジュール更新
1. 公開URLの `admin.html` を開きます。
2. 週タイプ・曜日を選び、タスクを追加・編集・削除します。
3. 「JSONを書き出す」で `schedule.json` を保存します。
4. GitHubリポジトリ内の `schedule.json` を置き換えてコミットします。
5. メンバーは再読み込みすると更新データを取得します。オフライン時は最後にキャッシュしたデータを表示します。

※管理画面の編集はその端末内に一時保存されるだけです。公開反映には必ずJSONの書き出しとGitHub側での更新が必要です。
※GitHub Pagesは公開サイトです。管理画面にパスワード認証はありません。公開前に運営関係者へ内容を確認してください。
※初期版のアラートはアプリを開いている間の画面内表示です。アプリを閉じた状態での通知は実装していません。
※チェック状態・アイテム数は各端末のブラウザ内に保存されます。ブラウザデータ消去や端末変更で失われる場合があります。
※週の切替・日付移動に伴うチェック状態は週開始日（月曜）と週タイプで分けて保存されます。

## 週タイプの自動切替
週タイプは月曜日を週の開始日として、毎週交互に自動判定します。2026年11月9日（月）開始週をエースコマンダー週とし、11月16日（月）開始週からファイター&シューター通常週です。

## 通知機能
初期版では通知・画面内アラート機能を設けていません。時間指定タスクはアプリ内の時間軸で確認できます。

## 週タイプ画像
ホーム画面上部には、日付から自動判定した週タイプを「今週はエースコマンダー」「今週は通常週」と表示します。該当する画像をタップすると別画面で拡大表示します。`img1.png` と `img2.jpg` は `index.html` と同じフォルダ（GitHubリポジトリ直下）に配置してください。


## ゲーム内日付の切り替わり

曜日・日付および週タイプは毎日9:00に切り替わります。9:00より前は前日のゲーム内日付として扱い、週タイプの切り替わりも月曜日9:00です。
